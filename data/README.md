# Data

The dataset is not committed to this repository.

**Dataset:** Online Retail, UCI Machine Learning Repository
**Link:** https://archive.ics.uci.edu/dataset/352/online+retail
**Contents:** 541,909 transactions from a UK-based online retailer, December 2010 to December 2011.

Download the Excel file, rename it to `online_retail.xlsx`, and place it in this directory. The notebook also writes `customer_segmentation_final.csv` here.
